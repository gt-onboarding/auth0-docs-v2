---
title: "Obtenir les métadonnées WS-Federation"
description: "Renvoie les métadonnées WS-Federation d’un tenant Auth0."
---

<div id="endpoint">
  ## Point de terminaison {#endpoint}
</div>

`GET /wsfed/FederationMetadata/2007-06/FederationMetadata.xml`

Ce point de terminaison renvoie les métadonnées WS-Federation.

<div id="learn-more">
  ### Pour en savoir plus {#learn-more}
</div>

* [WS-Federation](https://auth0.com/docs/authenticate/protocols/ws-fed-protocol)

<div id="response-messages">
  ## Messages de réponse {#response-messages}
</div>

| Statut | Description                                              |
| ------ | -------------------------------------------------------- |
| 200    | Réponse réussie contenant les métadonnées WS-Federation. |
